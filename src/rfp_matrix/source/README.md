# Source APIs and limits

`source` owns immutable extraction identity, original Unicode coordinates, literal resolution, structural inspection and pure human coverage decisions. Application-owned identity, SQLite transactions and CLI controls live in `review`/`cli`.

## Coverage inspection (policy `m3-human-original-page-inspection-v1`)

- `coverage_page_sha(artifact, page_index) -> str` hashes the complete page mapping, including structure and parser warnings.
- `make_coverage_decision(artifact, *, page_index, decision, reason, actor, request_id, expected_revision, previous=None, inspected_original=False) -> dict` prepares a deterministic event. Actions are `accept_blank`, `accept_text`, `flag_unresolved`. Only the application resolves `actor`; passing a string here is not authentication. Acceptance requires an explicit original-page inspection and nonblank reason.
- Initial expected revision is `None`; subsequent expected revision must equal the previous page event's `revision`. The application must compare that against persisted current state and enforce request-id identity in the same transaction that appends the event. Event hashes alone do not provide authorization or persistence.
- `effective_coverage(artifact, decisions=()) -> dict` replays complete ordered history for this exact artifact. Return fields include `complete`, `unresolved_pages`, per-page original issues/disposition/actor/reason, `audit_revisions` and `summary_revision`. Keep application timestamps/envelope fields outside the pure event. Wrong artifacts/pages, altered records, missing/forked history and request conflicts raise `M3Error`; never silently filter or rebind them.

Only genuinely blank (`empty`, no native text, no other warning) pages can receive `accept_blank`. Native-text sparse/table/column warnings may receive `accept_text` following explicit human original inspection. Unknown warnings, images/scans, broken text and extraction errors cannot be cleared by this policy. `flag_unresolved` can reopen any page. Acknowledgement does not rewrite the original artifact or prove extraction quality, requirement recall, vendor compliance, or redistribution rights. Artifact-level provenance notices remain visible in summaries. Changing coverage does not itself approve any row; application invalidation/reassessment must preserve generation lineage.

## Coordinates and Unicode

`parse_pdf` and explicitly synthetic `parse_text_pages` return content-addressed artifacts with raw source hash, parser/version/config identity and immutable original strings. New artifacts use Unicode-versioned `m3-nfkd-casefold-whitespace-<Unicode-version>-v2`. Compatibility decomposition, casefolding and canonical mark ordering retain a half-open original interval for every normalized codepoint; whitespace runs map to their complete original interval. Combining-mark reordering can make mapping intervals nonmonotonic. Legacy `m3-casefold-whitespace-alignment-v1` artifacts remain verifiable; `normalize_with_alignment(text)` retains its legacy default. New-policy mappings must pass `policy=artifact['normalization_policy']`. An unknown Unicode/policy version requires explicit re-extraction; it is never silently reinterpreted.

`anchor_from_normalized(artifact, page_index, start, end)` maps exact normalized offsets using interval union, checks roundtrip and rejects partial ligature/casefold/decomposition selections. `make_anchor` and `resolve_anchor` use exact original offsets and literal UTF-8 quote hashes; repeated quotes never use first-match lookup. New anchors keep a named section only if it contains the entire span; cross-section spans automatically retain exact coordinates with `section_id=None`. Legacy start-labelled section anchors remain resolvable as history. Split across pages into distinct anchors.

`resolve_context(artifact, anchors, radius=180)` resolves 1..100 literal anchors plus bounded same/adjacent-page context. Context outside the anchor is explicitly not evidence; multi-page obligations retain independent source pointers. UI page numbers are one-based; all source APIs use zero-based indices.

## Structural traversal and unsupported cases

`structural_segments(artifact, max_segments=10000)` visits all original nonblank lines with exact anchors, heading/bullet tags and parent-section identity. Wrapped lines retain uncertain atomicity. Separately preserved table cells have table/row/column indices and `anchor=None`: extracted cell strings do not establish original offsets or reading order. Table pages remain structurally unresolved. No guessed pixel geometry or first-substring table alignment is manufactured. Consumers must retain/review unresolved cells and cannot claim full inventory coverage from the line candidates alone. This function is additive; current evidence inventory has its own conservative paragraph traversal and needs a separately owned integration if this view is adopted.

The parser conservatively flags images, corrupt text, sparse/empty pages, tables and possible columns. More than 100 tables, excess pages/text/bytes or output IPC size fail visibly rather than truncate to a complete-looking artifact. Child CPU/memory caps, no-network hooks, bounded polling/joins and forced termination are source guards, not a verified OS security sandbox. Child startup, crash/EOF/oversize/invalid envelopes and inability to stop have typed failures. No OCR, raster/vector interpretation, guaranteed table alignment or reliable multi-column reconstruction is implemented. A short page is a warning only; character count never certifies it.
